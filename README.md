# Сравнение видеокарт у Мо

Сайт-каталог для сравнения GPU. Данные берутся из MySQL (файл `database/gpus_import.sql`, источник — `bd.csv`).

## Структура проекта

```
index.html        — только разметка страницы (верстка), без кода стилей/скриптов
css/style.css     — все стили сайта
js/features.js    — переключатели функций сайта (FEATURES)
js/app.js         — вся логика: загрузка карт, поиск, сравнение, счётчик популярности
api/config.php    — настройки подключения к базе (логин/пароль/имя БД) — менять вам
api/db.php        — общее подключение к MySQL
api/gpus.php      — отдаёт список видеокарт из БД в формате JSON
api/hit.php       — увеличивает счётчик «сколько раз карту выбрали в сравнение»
cpu.html          — страница сравнения процессоров
api/cpus.php      — отдаёт список процессоров из БД в формате JSON
api/cpu_hit.php   — счётчик популярности процессоров
database/gpus_import.sql — создание таблицы gpus + загрузка всех 1347 карт из bd.csv
database/cpus_import.sql — создание таблицы cpus + загрузка всех 3852 процессоров
bd.csv         — исходная таблица для генерации SQL (на сайте не используется)
```

## ⚠️ Импорт базы процессоров (обязательно, если нужна страница cpu.html)

Видеокарты и процессоры — это **две разные таблицы в одной базе `gpu_site`**.
Если вы импортировали только `gpus_import.sql`, страница процессоров будет пустой.
Нужно дополнительно импортировать `cpus_import.sql`:

1. Откройте phpMyAdmin (трей OpenServer → «Админ» → phpMyAdmin).
2. Слева выберите базу **gpu_site** — ту же самую, куда уже импортированы видеокарты (новую базу НЕ создавайте).
3. Вкладка **SQL** → вставьте содержимое файла `database/cpus_import.sql` целиком → «Вперёд».
   (Либо вкладка «Импорт» → выбрать файл `cpus_import.sql` → «Вперёд».)
4. Готово: появится таблица `cpus` (~3852 строки). Обновите страницу `cpu.html` — процессоры подгрузятся.

Проверка: откройте `http://ваш-домен/api/cpus.php?diag=1` — должно вернуть `"ok":true` и число строк больше нуля.
Если импорт повторяете — сначала удалите таблицу `cpus` (вкладка «Структура» → «Удалить»), чтобы не было дублей.

## Быстрый старт на OpenServer (локально)

1. Скопируйте папку проекта в `OpenServer/domains/` (например, создайте домен `gpu.local`).
2. Запустите OpenServer (Apache + MySQL).
3. Откройте phpMyAdmin (значок OpenServer в трее → «Админ» → phpMyAdmin).
4. Вкладка **SQL** → вставьте содержимое файла `database/gpus_import.sql` → «Вперёд». База `gpu_site` и таблица `gpus` будут созданы автоматически.
5. Проверьте `api/config.php`: по умолчанию `localhost / root / пустой пароль / gpu_site` — для стандартного OpenServer менять ничего не нужно.
6. Откройте `http://gpu.local/index.html`. Каталог заполнится из базы. Без запущенной MySQL список карт будет пустым — других источников данных нет.

## Запуск на Beget

1. Панель управления → «Базы данных MySQL» → создать базу (например `username_gpu_site`) и пользователя с паролем.
2. В этой же базе откройте phpMyAdmin → вкладка SQL → выполните содержимое `database/gpus_import.sql`, но **уберите первые две строки** `CREATE DATABASE ...;` и `USE ...;` (база уже создана), либо просто импортируйте файл через вкладку «Импорт».
3. Отредактируйте `api/config.php`: подставьте хост (`localhost`), имя базы, пользователя и пароль от Beget.
4. Загрузите все файлы проекта в корень сайта (обычно `www/ваш_домен/`) через файловый менеджер или FTP.
5. Откройте сайт по адресу — данные подтянутся из MySQL.

## Как работают правки из ТЗ

1. **Карты из таблицы.** В верстке нет тестовых строк; при загрузке страницы `js/app.js` запрашивает `api/gpus.php` (MySQL) — это единственный источник данных. Столбцы CSV раскладываются по ячейкам так же, как в прежней верстке.
2. **Год убран** из выпадающего списка поиска (в списке только название карты).
3. **Сортировка в выпадающем списке:** сначала самые популярные (сколько раз карту выбирали в сравнение), затем более короткие названия. Счётчик хранится в таблице `gpus.hits` (обновляется через `api/hit.php`) и дублируется в localStorage браузера.
4. **Память:** старые карты (до 2005 г.) хранят объём в МБ, новые — в ГБ; `ramCell()` в `js/app.js` определяет единицы по году и величине (TITAN RTX → 24 ГБ).
5. **Метки брендов** сокращаются до 4 символов максимум (TITAN → TTN, Tesla → TSL, Quadro → QDR и т.д.), квадратик не растягивается.
6. **Разделение на файлы** — см. структуру выше.
